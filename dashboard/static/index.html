SHARED EMIT(EVENT, PAYLOAD) BUS INTERFACE

Any team can publish data to the dashboard in real time using the shared event bus:

Python (Kinematics, NLP, Vision, Host)
from dashboard.events import emit

# 1. NLP Command & Parsing
emit("nlp:command_received", {"text": "pick up red cube"})
emit("nlp:parsed", {"actions": [...], "status": "accepted"})

# 2. Arm & Kinematics Steps
emit("planner:step_changed", {"step": "GRASP", "index": 5, "total": 9, "message": "Closing gripper claws"})
emit("arm:packet_sent", {"counter": 1043, "cmd": "MOVE", "targets": [90, 110, 105, 90, 75]})

# 3. Safety Enforcement
emit("safety:rejected", {"reason": "Target outside workspace reach radius"})
emit("safety:estop", {"triggered_by": "operator", "reason": "Stop button commanded"})

# 4. Vision Detections
emit("vision:detection_frame", {"count": 4, "detections": [...]})

# 5. Sensors & Production
emit("sensors:ina219_read", {"current_ma": 420.5, "voltage_v": 4.96})
emit("stats:production_update", {"parts_sorted": 15, "rejects": 2})
HTTP REST / C / Firmware / Curl
curl -X POST http://localhost:8000/api/emit \
  -H "Content-Type: application/json" \
  -d '{"event": "arm:packet_ack", "payload": {"counter": 1043, "accepted": true}}'

Documented Event Names:

  • nlp:command_received: Operator natural language input
  • nlp:parsed: Parsed action list & acceptance status
  • nlp:clarification_needed: Ambiguity detection & questions
  • safety:rejected: Rejection with explicit failure reason
  • safety:estop: Emergency stop triggered
  • safety:reset: System re-armed and reset to safe ready
  • planner:step_changed: Active trajectory phase update
  • arm:status_update: 5-DOF joint angles & comms state
  • arm:packet_sent / arm:packet_ack: Armlink protocol packets
  • vision:detection_frame: Detected objects & bounding boxes
  • sensors:ina219_read: Current, voltage, & power draw
  • stats:production_update: Sorted, rejects, and cycle time
